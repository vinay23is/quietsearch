Privacy

What this instance protects, what it doesn't, and what each party involved can still see.

This instance reduces how much individual search providers learn about you. It does not make you anonymous.

What this server stores

  • No accounts and no search history.
  • No access logs. The reverse proxy writes no per-request log, so search queries in URLs are never written to disk.
  • Application logs contain warnings and errors only (for example, a provider timing out). Container logs are rotated at 30 MB per service.
  • Rate limiting keeps a short-lived, in-memory counter per IP address (at most one minute).
  • Your preferences (theme, providers, SafeSearch) are stored in cookies in your own browser, not on the server.

Who can see what

PartyWhat they can still see
Search providers (DuckDuckGo, Bing, Brave, ...) The text of each query, sent from this server's IP address with a generic browser identity. Not your IP, cookies, or account. On a single-user instance, the server's IP effectively stands for you, so a provider could still link queries that come from it. Every enabled provider in a category receives each query in that category.
Hosting provider The server's network traffic: which providers it contacts and when. Your connection to the server is encrypted with HTTPS.
The operator of this instance Anything the server could record. This instance is configured not to log queries, but you are trusting that configuration.
Your internet provider / network That you connect to this server's address and domain name, when, and how much data. Not your queries.
DNS resolvers Your resolver sees lookups for this instance's domain name, not your queries.
Websites you open from results Everything a normal visit reveals: your IP address, browser and cookies. This instance hides the search page you came from (no Referer header), but the visit itself is direct.

Built-in protections

  • HTTPS only, including HSTS; plain HTTP is redirected.
  • Image previews are fetched through this server, so image hosts don't see your IP while you browse results.
  • Autocomplete is off by default. When turned on, each partial query is sent to a provider as you type.
  • Tracking parameters (such as utm_*) are removed from result links.
  • The search query is kept out of page titles, so it doesn't appear in window titles or history titles.

If you need more

To hide your IP address from websites you visit, or your use of this instance from your network, use a VPN or Tor in addition to this service.
